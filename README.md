# ONLY YOU ❤️

An Arabic-first romantic Android app concept for Shahed, built with Kotlin.

## What's included
- Dark cinematic purple theme
- ONLY YOU home screen
- Interactive letter, memories, and surprise sections
- GitHub Actions workflow that generates the Gradle wrapper and builds a debug APK

## Build locally
Open this project in Android Studio and let Gradle sync.

## Build on GitHub
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository's root.
3. Open the **Actions** tab.
4. Select **Build ONLY YOU APK** and run it, or push a commit to `main`.
5. When the workflow finishes, open the run and download the `ONLY-YOU-debug-apk` artifact.

## Customize
Edit the messages in `app/src/main/java/com/onlyyou/shahed/MainActivity.kt`.
